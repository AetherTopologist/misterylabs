# MisterY Labs Visual Hierarchy Doctrine v1

## Layer Stack

Every page should be understandable when squinting.

Visual hierarchy:

1. Background Layer
2. Diagram Layer
3. Annotation Layer
4. Content Layer
5. Action Layer

### Background Layer

Purpose:
Provide atmosphere.

Examples:

* page background
* observatory gradients
* decorative effects

Rule:
Never contain critical information.

---

### Diagram Layer

Purpose:
Show phenomena.

Examples:

* transport sphere
* resonance sphere
* force graph
* visual simulations

Rule:
May contain data.
Must not contain essential reading text.

---

### Annotation Layer

Purpose:
Explain diagrams.

Examples:

* instrument labels
* axis labels
* transport labels
* metadata

Rule:
Must sit on a dedicated surface.

Preferred:

* translucent plate
* frosted strip
* annotation card
* instrument tag

Avoid:
Text directly over diagrams.

---

### Content Layer

Purpose:
Communicate meaning.

Examples:

* headlines
* descriptions
* explanatory copy

Rule:
Must always dominate annotation text.

---

### Action Layer

Purpose:
Guide navigation.

Examples:

* CTAs
* links
* filters

Rule:
Always visually distinct from content.

---

## Observatory Principle

Do not solve readability problems with color first.

Solve them with layers first.

Preferred:

Background
→ Surface
→ Content

Avoid:

Background
→ Diagram
→ Text
