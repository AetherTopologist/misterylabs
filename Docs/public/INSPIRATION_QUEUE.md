# MisterY Labs Inspiration Queue

Capture external ideas worth investigating without assuming provenance or
committing to implementation.

Each entry should record:

- Title
- Source / discovery URL
- Original creator, or `UNRESOLVED`
- Concept
- What misconception the demonstration dissolves
- Possible MisterY Labs experiment
- Possible xPRIMEray connection
- Attribution status
- Status: captured / researching / prototype / published
